{{ _('How to use') }}

{{ _('Secret Santa helps you organize a gift exchange without accounts. Each participant gives one gift and receives one gift, and nobody draws themselves.') }}

{{ _('For organizers') }}

  1. {{ _('Create event') }}. {{ _('Choose a title, icon, gift budget, currency, and exchange date. Add notes if needed. Enable no reciprocal pairs if two people must not draw each other.') }}
  2. {{ _('Copy organizer link') }}. {{ _('Save the private organizer link immediately. It is your access to the dashboard: there is no login or recovery if you lose it. Anyone with this link can manage the event.') }}
  3. {{ _('Enable wishlists') }}. {{ _('Wishlists are enabled by default. Change this setting on the organizer page at any time. Turning it off hides saved wishes without deleting them; they reappear when enabled again.') }}
  4. {{ _('Add participant') }}. {{ _('Add 2 to 32 people. You can enter their gift ideas and edit or remove participants while the event is a draft.') }}
  5. {{ _('Subgroups') }} / {{ _('Directed exclusions') }}. {{ _('Optionally create groups for households or couples, add their members, and enable no intra-group draws. Individual exclusions prevent a specific giver from drawing a specific recipient; they do not automatically apply in reverse.') }}
  6. {{ _('Check rules') }}. {{ _('This checks whether a complete draw is possible with the saved rules. The result appears below the button and is also checked when the dashboard loads. If nothing changed, clicking again may show the same result. This does not save assignments or activate links. If the rules prevent a draw or the check cannot finish, adjust a restriction and try again.') }}
  7. {{ _('Run draw') }}. {{ _('Create the assignments once the rules allow a draw. The dashboard does not display all pairings.') }}
  8. {{ _('Lock and enable links') }}. {{ _('Activate the private participant links, then copy each link and send it only to that person. The service does not send emails or messages automatically. Other event settings, participants, and rules can no longer be changed, but the wishlist setting and enabled wishlists remain editable.') }}

{{ _('For participants') }}

{{ _('Open the private link your organizer sent you to see your recipient, the budget, the exchange date, and their gift ideas if wishlists are enabled. You cannot see who drew you.') }}

{{ _('If wishlists are enabled, use Your wishlist to enter your own gift ideas, then save them. Return to the same link to update them; the person giving to you sees your latest saved wishlist. Participant links are available only after the organizer locks the draw. Before that, ask the organizer to enter your ideas.') }}

{{ _('Keep links private') }}

{{ _('Anyone with a participant link can see that assignment and edit that participant’s wishlist. Do not share your organizer or participant link publicly.') }}

{{ _('To change a draw, the organizer must confirm Reset draw. This deletes the assignments and invalidates old participant links. Run and lock a new draw, then send the new links. Resetting cannot make someone forget a recipient they already saw. If your link stops working, contact your organizer.') }}
